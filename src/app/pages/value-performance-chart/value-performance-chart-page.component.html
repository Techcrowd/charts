Value Performance Chart

Graf pro zobrazení vývoje hodnoty investice v čase s volitelnou křivkou investované částky.

Základní zobrazení

Graf s křivkou hodnoty portfolia (zelená výplň) a křivkou investované částky (stepline).

Hover s externím zobrazením hodnot

Hover nad grafem zobrazí puntík a hodnoty jsou emitovány mimo komponentu přes (pointHover) event.

Barevné varianty

Barva grafu se nastavuje v konfiguraci čáry pomocí color vlastnosti.

Pozitivní trend (zelená)

Negativní trend (šedá)

S křivkou investované částky

Konfigurace s dvěma čárami - hodnota a investovaná částka.

Stepline křivka

Schodovitá křivka pro diskrétní změny hodnot - vhodné např. pro zobrazení NAV fondu.

Volatilní data

Graf s velkými výkyvy hodnot - zobrazení rizikových investic.

Neúplný interval

Data končí dříve než časový rozsah osy X - např. zobrazení aktuálního měsíce kde data ještě nejsou kompletní. Použijte [xAxisMax] pro nastavení konce osy X.

Časové intervaly

Různé časové intervaly s odpovídající granularitou dat a formátem datumu.

1 den

5 dnů

1 měsíc

1 rok

5 let

Minimální varianta

Graf bez legendy a anotací - jen čistá křivka.

Loading stav

Skeleton zobrazený během načítání dat.

Vlastní barvy

Graf s vlastními barvami z palety - chart-stocks a chart-bonds.

Datové typy

API Reference

Inputs

Input Typ Default Popis
[lines] ChartLine[] [] Pole čar - každá čára obsahuje svou definici i data
[height] number 300 Výška grafu v px
[showHighLowValues] boolean true Zobrazit high/low anotace
[showLegend] boolean false Zobrazit legendu
[showTooltip] boolean false Zobrazit tooltip
[showGrid] boolean false Zobrazit mřížku
[showYAxis] boolean false Zobrazit Y osu
[xAxisMin] Date | number | string - Min. hodnota osy X (pro neúplné intervaly)
[xAxisMax] Date | number | string - Max. hodnota osy X (osa pokračuje za data)
[valueUnit] string '' Jednotka hodnoty (měna)
[dateFormat] string 'dd.MM.yyyy' Formát datumu (dd, MM, MMM, yyyy, HH, mm)
[loading] boolean false Loading stav
[nonce] string - CSP nonce pro inline styly

ChartLine

Vlastnost Typ Popis
name string Název čáry (legenda, tooltip)
color ChartColor Barva z palety
curveType 'smooth' | 'straight' | 'stepline' Typ křivky
data ChartDataPoint[] Pole datových bodů {{ '{ x, y }' }}

Outputs

Output Typ Popis
(pointHover) {{ '{ timestamp, values: { name, value }[] }' }} | null Hover nad bodem - obsahuje hodnoty ze všech čar
(pointClick) {{ '{ timestamp, values: { name, value }[] }' }} Kliknutí na bod

Content Projection

Pro vlastní ovládací prvky použijte ng-content slot:

<co-value-performance-chart [lines]="lines">
  <co-tab [options]="intervals" (change)="onIntervalChange($event)" />
</co-value-performance-chart>
