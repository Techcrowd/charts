Návod na úpravy – Donut & Broker Chart

1. Donut chart – šířka prstence +4px

Soubor: src/app/components/co-donut-chart/co-donut-chart.component.ts
Řádek: ~244

Vlastnost computedDonutSize určuje velikost vnitřní díry donutu (v % z poloměru). Menší procento = širší prstenec. Při height 280px: poloměr ~140px, ring = 140 × (1 - 0.77) = 32.2px → pro +4px: 36.2px → size = 1 - 36.2/140 ≈ 74%.

Změnit

computedDonutSize = '77%';

Na

computedDonutSize = '74%';

Celková velikost (height) zůstává beze změny na 280px. Mění se jen poměr díry, čímž se prstenec rozšíří o ~4px.

2. Broker chart – hover puntík jen u jedné křivky

Soubor: src/app/components/co-value-performance-chart/co-value-performance-chart.component.scss
Řádek: ~163 (za existující pravidlo .apexcharts-marker { transition: none; })

Přidat za existující pravidlo

// Existující pravidlo (NEMĚNIT):
.apexcharts-marker {
  transition: none !important;
}

// NOVÉ – zobrazit hover marker jen u první křivky
.apexcharts-series-markers-wrap:not(:first-of-type) .apexcharts-marker {
  opacity: 0 !important;
  r: 0 !important;
}

Toto pravidlo patří dovnitř bloku :host ::ng-deep { ... }, který už v souboru existuje (řádek 121). Tooltip se stále zobrazí s hodnotami obou křivek, ale vizuální puntík na grafu bude jen u první (hlavní) křivky.
