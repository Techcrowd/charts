1. Hover — aktivace jen dané skupiny záměrná změna

Jediná funkční odchylka. Produkce při hoveru na sloupec přidává třídu co-column-chart--hovering, která přes CSS ztmaví všechny série v celém grafu. V replice je celoplošné ztmavení odstraněno a nahrazeno JS metodou highlightBars(), která pracuje jen se sloupci v hoverované skupině. Tohle je úprava, kterou chceme přenést do produkce (návod pro produkci: ZMENY-NAVOD.html, bod 3).

// HTML — class binding odstraněn, SCSS blok odstraněn

// dataPointMouseEnter — navíc volá highlightBars()
dataPointMouseEnter: (event, chartContext, config) => {
  const { seriesIndex, dataPointIndex } = config;
  self.hoveredSeriesIndex.set(seriesIndex);
  self.highlightBars(seriesIndex, dataPointIndex);   // <-- NOVÉ
  ...
},
dataPointMouseLeave: () => {
  self.hoveredSeriesIndex.set(-1);
  self.highlightBars(-1, -1);                        // <-- NOVÉ
  self.columnHover.emit(null);
},

/**
 * Dimuje ostatní sloupce ve stejné skupině při hoveru.
 * Sloupce z jiných skupin zůstávají nedotčeny.
 */
private highlightBars(activeSeriesIndex: number, activeDataPoint: number): void {
  if (!this.isBrowser) return;
  const bars = this.elementRef.nativeElement
    .querySelectorAll('.apexcharts-bar-area') as NodeListOf<SVGElement>;
  bars.forEach(bar => {
    if (activeDataPoint === -1) {
      bar.style.removeProperty('opacity');
    } else {
      const seriesIdx = parseInt(bar.getAttribute('index') ?? '-1', 10);
      const j = parseInt(bar.getAttribute('j') ?? '-1', 10);
      if (j === activeDataPoint) {
        // stejná skupina: hovered bar plný, ostatní bary skupiny ztmaví
        bar.style.opacity = seriesIdx === activeSeriesIndex ? '1' : '0.35';
      }
      // jiná skupina (j !== activeDataPoint): nedotýkat se
    }
  });
}

2. DsContextService / graphColorsSync$ vynecháno

Produkce synchronizuje barvy grafu do aplikačního kontextu. Demo žádný DsContextService nemá a na vizuál ani chování grafu to nemá vliv — celý mechanismus je vynechán.

Produkce (originál z fotek) — v replice není

private dsContextService = inject(DsContextService);
private readonly graphColorsSync$ = new Subject<string[]>();
private graphColorsSyncSub?: Subscription;

// ngOnInit:
this.graphColorsSyncSub = this.graphColorsSync$
  .pipe(
    filter(colors => colors.length > 0),
    distinctUntilChanged((prev, curr) => this.areColorArraysEqual(prev, curr)),
  )
  .subscribe(colors => {
    this.dsContextService.setGraphColors(colors);
  });

6. displayValue přidán do sdílené demo legendy doplnění demo infrastruktury

Produkční ChartLegendItem (v chart-legend/co-chart-legend.component) pole displayValue už má — demo legenda ho neměla. Doplněno zpětně kompatibilně (optional pole, ostatní grafy v demu nedotčeny).
